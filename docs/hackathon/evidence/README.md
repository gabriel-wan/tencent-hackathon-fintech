# CodeBuddy / WorkBuddy usage evidence

The hackathon requires proof that the project was built with CodeBuddy or
WorkBuddy: **a minimum of 3 screenshots or a screen recording of development
chat logs**. Without proof the project is not scored.

Store the real evidence in this folder as it is captured during development.
Nothing here may be fabricated or staged after the fact.

Suggested naming: `YYYY-MM-DD-<tool>-<topic>.png` (or `.mp4`), for example
`2026-09-25-codebuddy-architecture-review.png`.

Keep a short log in [../tool-usage.md](../tool-usage.md) of what each file shows.
Do not store anything containing secrets, tokens, or personal data of people
outside the team; crop or redact before committing.
